# Automated-PCB-Validation-Test-Analytics-Platform


The Automated PCB Validation & Test Analytics Platform is a software-based hardware test environment developed in Python and C to simulate the automated validation of electrical PCBs. The platform models a configurable device under test (DUT) alongside virtual laboratory equipment including a digital multimeter, programmable power supply, electronic load, and oscilloscope. Python-based test sequences automatically configure operating conditions, collect voltage, current, power, and ripple measurements, compare results against configurable engineering limits, and determine pass/fail status. The system also supports hardware fault injection, allowing conditions such as undervoltage, excessive ripple, overcurrent, and high temperature to be introduced to verify test coverage and failure detection. Test results are processed using Pandas and exported as CSV, JSON, and PDF engineering reports. A separate C command-line waveform analyzer processes simulated oscilloscope data to calculate RMS voltage, mean, minimum, maximum, and peak-to-peak measurements, demonstrating integration between Python automation software and Linux-based C analysis tools. The project was designed to replicate a simplified R&D/production PCB validation workflow while remaining completely software-based and requiring no external laboratory hardware.
